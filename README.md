# ATAS Pivot Points

ATAS 主图枢轴点指标，图表中的名称为 **Pivot Points**。根据上一个参考周期的高、低、收盘等价格，计算本周期的 P、R1、R2、R3、S1、S2、S3。

本仓库于 2026-11-12 从现有指标中单独摘出。生产源码保持原样；不是后续的 `Pivot Heatmap Experimental` 热区指标。

## 功能

|项目|当前行为|
|---|---|
|计算方法|经典、伍迪、斐波那契、卡玛利拉；“全部”同时计算四种|
|参考周期|跟随图表、1/5/10/15/30 分钟、1/2/4/6/8/12 小时、日、周、月、季|
|伍迪加权价|上一周期收盘或当前周期开盘|
|显示过滤|可选择仅显示最新图表柱所在交易日|
|样式|P、R1–R3、S1–S3 七组统一设置；P 默认 8 px，其余 3 px|
|数据|读取 ATAS 当前图表已经加载的 K 线；无需网络接口|

首次观察建议在 5 分钟时间图中，选择“经典 / 日 / 周期起点小时 0”，先识别七条线，再切换“全部”。需要加载前一参考周期及当前周期的数据；第一段历史可能不完整，详细处理见算法说明。

“全部”包含 28 条计算序列；相同价位会重合。当前版本显示水平线，不合并成支撑阻力区域，也不显示热度。

## 快速验证

安装 .NET 10 SDK 后，在仓库根目录运行：

```powershell
dotnet run --project tests/PivotMath.Check/PivotMath.Check.csproj -c Release
```

公式测试无需安装 ATAS。构建指标本身需要合法安装的 ATAS 程序集，具体见构建说明。

P 是公式计算的轴心参考价；R/S 是按公式命名的阻力/支撑参考价。其预测能力和可执行交易效果需要另行验证。仓库没有账户接入或下单功能。
