# 构建与安装

## Windows 构建

需要 .NET 10 SDK，以及本机 ATAS 提供的 ATAS.Indicators、ATAS.DataFeedsCore、OFT.Rendering、OFT.Attributes、Utils.Common 程序集。

在仓库根目录执行：

```powershell
dotnet build src/PivotPoints/PivotPoints.csproj -c Release
```

默认 ATAS 目录为 `C:\Program Files (x86)\ATAS Platform`。其他安装路径可显式指定：

```powershell
dotnet build src/PivotPoints/PivotPoints.csproj -c Release '-p:ATAS_BASE=D:\Applications\ATAS'
```

输出为 `src/PivotPoints/bin/Release/net10.0-windows/PivotPoints.dll`。

项目原样保留 ATAS X 的 Cross 配置：

```powershell
dotnet build src/PivotPoints/PivotPoints.csproj -c Release -p:Platform=Cross
```

该配置默认从 `C:\Program Files\ATAS X` 引用依赖，目标 `net10.0`。本次只验证 Windows 构建，Cross 配置未在 ATAS X 实际运行验收。

ATAS 的依赖 DLL 不包含在此仓库中，需要使用自己安装版本提供的程序集。旧版 ATAS 是否能加载 .NET 10 指标需要另行核对。

## 下载编译好的 DLL

从 [v2026.11.12.2 发布页](https://github.com/AegonVibeCoding/Pivot-Points/releases/tag/v2026.11.12.2) 下载 `PivotPoints.dll` 和 `SHA256SUMS.txt`。仓库 `artifacts/PivotPoints.dll` 保存相同的编译文件，图表名称为 `Pivot Points`。

此文件于 2026-11-12 从当前独立工程完整重编译，目标为 Windows / .NET 10；没有包含 ATAS 依赖程序集。下载后可运行 `Get-FileHash .\PivotPoints.dll -Algorithm SHA256`，与校验文件比较。

独立路径重新编译可能因构建路径和 SDK 等原因产生不同的 DLL 哈希；这不等于指标公式发生变化。源码对应记录见[版本与验证](版本与验证.md)。

## 手动安装

1. 保存工作区，并退出 ATAS。
2. 确认自己 ATAS 实例使用的自定义 Indicators 目录，将已有同名 DLL 备份到该目录之外。
3. 将 `PivotPoints.dll` 放入该目录。不要把旧副本换个 DLL 文件名后也留在扫描目录，避免重复发现同一个指标。
4. 启动 ATAS，在指标列表搜索 `Pivot Points`。

摘出时本机使用的目录是 `%APPDATA%\ATAS\Indicators`；不同安装和用户配置可能不同，应以对应实例为准。

仓库整理和上传不会自动安装、覆盖、重启或操作 ATAS。

本版统一了程序集、命名空间和类名，ATAS 可能将其识别为新的指标类型。升级时先移除图表上的旧实例，关闭 ATAS，把旧 DLL 移出扫描目录，再放入新 DLL 并重新添加 `Pivot Points`。原工作区模板不保证自动迁移。

## 自检与持续集成

```powershell
dotnet run --project tests/PivotMath.Check/PivotMath.Check.csproj -c Release
```

自检直接编译同一份 `PivotMath.cs`，覆盖固定输入输出、已有截图回归、伍迪两种口径及错误输入。GitHub Actions 只运行这套纯公式检查；不下载或分发 ATAS SDK，不代表图表实时显示已验收。
