## 本次验证范围

本次整理执行源码副本哈希比对、已安装 DLL 哈希比对、独立项目 Windows Release 编译，以及 17 项纯公式检查。具体执行结果见仓库根目录 `verification.json`。

公式检查包含五组教学示例、三组既有截图回归、四种公式的平价输入、三种非伍迪方法对当前开盘的独立性，以及两种错误输入。截图回归仅覆盖保存的单组数字。

尚未由本次任务验收的项目：ATAS 图表实时回放、跨日显示过滤、图表原始时间与显示时区的关系、ATAS X 运行，以及不同 ATAS 版本加载兼容性。

## 与已有研究的关系

`Pivot Points` 是单价位线条指标。后续多周期热区研究采用不同的会话、ATR、聚类和数据质量规则；热区研究中的数值对照与统计结论不能直接当作本指标的验证报告。

本次工作是保存当前版本并整理说明，没有更改生产计算逻辑，也没有建立获利或概率校准结论。
