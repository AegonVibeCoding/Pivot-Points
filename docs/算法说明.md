# Pivot Points 指标算法说明

依据：仓库 `src/PivotPoints/PivotMath.cs` 和 `Jin10PivotIndicator.cs`，2026-11-12 摘出版本。下面描述当前代码的实际行为。

## 1. 输入与输出

- H、L、C：上一个已聚合参考周期的最高、最低、最后收盘。
- O：新参考周期第一根可见 K 线的开盘，仅伍迪当前开盘口径使用。
- Δ = H − L。
- 输出：P、R1、R2、R3、S1、S2、S3，内部使用 C# `decimal`。

前周期 Open 会保存在 OHLC 记录中，当前四套公式不使用它。公式入口拒绝 H<L；没有进一步校验 C 是否位于 H/L 之间。`全部` 由指标层逐个调用四套公式，不能直接作为单一公式传给 `PivotMath.Calculate`。

## 2. 经典：源码 Classic，公式对应 Traditional 口径

```text
P  = (H + L + C) / 3
R1 = 2P − L             S1 = 2P − H
R2 = P + Δ              S2 = P − Δ
R3 = H + 2(P − L)       S3 = L − 2(H − P)
```

不同软件对 Classic/Traditional 的命名可能不同。对照时应比较 R3/S3 的实际公式，不能只比较中文“经典”。本版本 R3 不是 `P + 2Δ`。

## 3. 伍迪

先选加权价 W：默认 W=C；选择“当前周期开盘”时 W=O。

```text
P  = (H + L + 2W) / 4
R1 = 2P − L             S1 = 2P − H
R2 = P + Δ              S2 = P − Δ
R3 = H + 2(P − L)       S3 = L − 2(H − P)
```

“全部”模式也遵循同一个伍迪加权价设置。

## 4. 斐波那契

```text
P  = (H + L + C) / 3
R1 = P + 0.382Δ         S1 = P − 0.382Δ
R2 = P + 0.618Δ         S2 = P − 0.618Δ
R3 = P + Δ              S3 = P − Δ
```

## 5. 卡玛利拉

```text
P  = (H + L + C) / 3
F  = 1.1Δ
R1 = C + F/12           S1 = C − F/12
R2 = C + F/6            S2 = C − F/6
R3 = C + F/4            S3 = C − F/4
```

当前版本只画到第三级，没有 R4/S4。R/S 围绕 C 展开，而 P 由 H/L/C 均值计算，因此不能保证 P 始终夹在 S1 和 R1 之间。

## 6. 参考周期如何划分

使用 `GetCandle(bar).Time` 原值，不执行时区转换。设起点小时为 a，先计算 `t′ = t − a小时`，再求桶起点，最后加回 a 小时。

|参考周期|t′ 的桶起点|
|---|---|
|跟随图表|直接返回原始 t，不做小时平移|
|分钟/小时周期|`floor(t′.Ticks / duration.Ticks) × duration.Ticks`|
|日|t′ 所在日期的 00:00|
|周|t′ 所在周星期一 00:00|
|月|t′ 所在月第一天 00:00|
|季|t′ 所在季首月第一天 00:00；首月为 1/4/7/10|

日内固定间隔按 DateTime ticks 网格对齐；提供的分钟/小时周期均整除 24 小时。周末、节假日或停盘没有独立交易所日历处理。

界面文字写有“按图表时区设置”，但代码实际没有调用图表时区转换 API。使用者必须先核对 ATAS 提供的原始时间与显示时间关系。该版本的起点小时不能替代完整时区和夏令时转换。

## 7. 聚合与更新顺序

1. 第一根可用柱建立当前聚合器，保存该柱 O/H/L/C；先不输出点位。
2. 后续柱若仍在同一桶：High 取最大、Low 取最小、Close 用当前柱收盘。
3. 遇到新桶：使用旧聚合器计算七个价位，伍迪当前开盘口径取新柱 Open；在上一柱设置线段终点；用新柱建立下一聚合器。
4. 在新周期各柱写入已经算好的价位。当前周期价格变化只更新聚合器，供下一周期使用。

正常顺序行情下，本周期点位不会随本周期尚未完成的 H/L/C 变化。新周期有首根实际柱时才切换，不按电脑时钟提前生成。重载历史或修改参数会触发重新计算。

“上一周期”是上一段实际聚合到的数据，不必然是紧邻的完整日历周期。中间整桶没有数据时，代码仍使用上一段聚合数据；没有缺柱或会话完整性门槛。历史从周期中间开始时，第一段不完整聚合也会用于下一周期。

算法按柱起始时间把整根柱归桶，不将跨桶柱拆开。因此图表需要有足够细、边界对齐的 K 线；程序不会自动下载参考周期所需的更小周期数据。

## 8. 取整

开启“按最小跳动取整”，且 ATAS 提供有效 TickSize 时：

```text
绘图值 = Round(原始值 / TickSize, 0, AwayFromZero) × TickSize
```

取整发生在写入绘图序列时，公式计算与 OHLC 聚合使用未取整的值。没有有效 TickSize 或关闭该选项时直接绘制公式值。恰好半个 tick 的正值向更大价格取整。

## 9. 显示过滤与统一样式

交易日期定义为 `(Time − 起点小时).Date`。仅显示当日时，当前柱交易日期与最新图表柱交易日期相同才写值，否则写 0；隐藏的历史仍参与聚合。

指标创建 4×7 条内部计算序列，另有七条样式模板。模板按同名级别同步颜色、线宽、虚线、绘图类型、当前值显示、零值显示、缩放、覆盖价格及提示属性。默认零值隐藏，当前值显示。原始方法前缀保留在内部序列名称中。

当前版本没有价位合并、热度、ATR 带宽、来源权重、突破状态机、概率标签或交易信号。
